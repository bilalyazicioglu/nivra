# Nivra documentation

Nivra records command boundaries and Git state locally so you can compare a working baseline with a later moment. It was previously codenamed Rewind.

- [Quickstart](Quickstart.md): build, record, mark, compare.
- [Architecture](Architecture.md): data flow, schema and capture boundaries.
- [Privacy](Privacy.md): stored metadata and recording controls.
- [Development](Development.md): contributing, checks and release gates.

Status: early source alpha. Runtime/port tracking and interactive TUI are not shipped. The documentation in `docs/wiki` is reviewed with code; the GitHub Wiki is a published mirror.
